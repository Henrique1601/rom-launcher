# 🧠 Second Brain: ROM Launcher & Downloader (rom-cli)

Bem-vindo à base de conhecimento perpétua do projeto **ROM Launcher**.  
Este diretório é o cérebro do projeto, mantido sob a governança do **`memory-architect-agent`** e do **`global-master-agent`**, garantindo **Zero Amnésia** para qualquer desenvolvedor ou agente de IA que atue nesta base de código.

---

## 🗂️ Estrutura da Memória

- [`_rules/`](./_rules/): Regras inegociáveis de engenharia de software e padrões de código.
- [`decisions/`](./decisions/): Architecture Decision Records (ADRs) detalhando o porquê de cada escolha tecnológica.
- [`gotchas/`](./gotchas/): Registro de armadilhas superadas, bugs sutis e soluções técnicas específicas do Windows.
- [`architecture/`](./architecture/): Diagramas de fluxo, componentes e topologia do sistema.
- [`handoffs/`](./handoffs/): Estado atual da esteira de desenvolvimento e próximos passos prioritários.
